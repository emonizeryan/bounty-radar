## Live API field-mapping fix

**What was wrong**: `loadLiveMakefun()` read `c.prize_pool_usd ?? c.prizePoolUsd ?? null` for the pool, but the real make.fun API (verified live) uses `potUsd` (string, e.g. "500.00"), with `rewardAmount` and `deadline` as fallbacks. No `prize_pool_usd` or `entries_close_at` fields exist. All live bounties were scoring 45 (no pool found) with prize text "prize pool".

**What was changed**:
- Updated pool lookup: `c.potUsd ? parseFloat(c.potUsd) : (c.prize_pool_usd ?? c.prizePoolUsd ?? c.rewardAmount ?? null)`
- Fixed deadline lookup: removed non-existent `c.entries_close_at`, kept `c.deadline || null`
- Score formula unchanged: `30 + round(log10(pool+1)*10)` capped at 65
